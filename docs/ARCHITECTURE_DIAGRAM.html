Antarctic Navigation Architecture

AI-enabled sea-ice forecasting, iceberg trajectory prediction, and navigation decision support for the Cape Town → Bharati resupply corridor. This is what the system is, what runs today, and what is still only designed.

Vessel MV Vasiliy Golovnin Corridor 0–80°E, 55–78°S Code 3,508 lines Python Data 1,096 real daily satellite files Synthetic data none

Ashore: everything that needs bandwidth or a GPU. Aboard: everything that needs to answer a question. Across the link: a compressed environmental state — never an answer.

That single rule produces the entire shape of the system, and it is forced by one physical fact: geostationary VSAT does not reliably reach south of about 70°S. Polar comms are Iridium-class. A decision-support tool that calls a live data API from the bridge is assuming infrastructure the ship does not have. So the vessel receives the environment and computes its own answers — which is also why the master can ask a second question, and a third, without waiting on a satellite.

4 · What is not built yet

Drawn dotted in the figures above. All are design decisions with known options — none needs a research breakthrough, which is the thing worth being able to say out loud.

  • Time-expanded routing graph. One mesh layer per forecast day. The single change that makes a forecast usable by a router at all — today the mesh is frozen at day zero.
  • Iceberg trajectories over time. The physics is done and tested; it needs an ocean current field to step forward. Both inputs are free.
  • Five-model ensemble and conformal calibration. Specified with a pre-committed pass/fail gate, so the result cannot be quietly reinterpreted afterwards.
  • Thickness channel, for POLARIS compliance. Forced by IMO regulation, not scope creep: POLARIS is indexed by ice type, so concentration alone cannot satisfy it.
  • Bathymetry. A free download; depth currently constrains nothing in the router.
  • Vessel force limit. Golovnin's dimensions are verified across four registries, but the ice-resistance force limit is still borrowed from a different hull. Disclosed, not hidden.
  • Ice compression risk field — genuine white space. Compression is the hazard that traps ships, and no Antarctic service forecasts it. Blocked on one data decision: modelled drift, or our own feature tracking.
