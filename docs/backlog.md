- [critical][ml] **Wagner drag-coefficient trap**: the arXiv preprint's text says `Ca=0.9, Cw=1.3`; the author's reference MATLAB says `Ca=1.3, Cw=0.9`. Only the code reproduces the paper's own γ=0.018 and L*=765 m. Use Ca=1.3/Cw=0.9 and assert `gamma≈0.0187` in a unit test — getting it backwards is a 44 % error in wind-driven drift — see docs/ICEBERG_RESEARCH.md §b.4.
- [major][ml] **Wagner Southern-Hemisphere sign flip is INFERRED, not confirmed.** WDE17's reference code uses `abs(lat)` in the Coriolis term and a fixed right-of-wind rotation, i.e. it is hard-coded to NH deflection; SH should deflect left. Negligible for USNIC giants (R<0.13) but material below ~1 km. Resolve empirically against BYU tracks or ask the authors — see docs/ICEBERG_RESEARCH.md §b.5.
- [major][ml] **Λ must be built from |f|, not signed f.** Eq. (9) as printed writes `f`; plugging a signed southern f gives Λ<0, β<0 and a backwards along-wind term. Also clip β's inner bracket at 0 — it is ~2Λ¹² and underflows to NaN for Λ≲0.05, which is *every* USNIC-tracked berg — see docs/ICEBERG_RESEARCH.md §b.5, §b.6.
- [minor][ml] IDRIFTNET's ADE/FDE (49.1/63.3 km A23A; 22.9/10.9 km B22A) are whole-rollout errors over an **unstated** horizon; train/test split also unstated. Never present them as 1/3/7-day figures — see docs/ICEBERG_RESEARCH.md §c.2.
- [minor][ml] Physics-only WDE17 baseline measured by IDRIFTNET at 147 km (A23A) / 127 km (B22A) geodesic ADE — this is the number that justifies the hybrid design; reproduce it on our own data before quoting it as ours — see docs/ICEBERG_RESEARCH.md §c.2.
